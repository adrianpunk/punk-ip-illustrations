# 个人 IP 创建工作流

## 目录

- 输入要求
- 固定身份提取
- 角色设定板与生成提示骨架
- 干净人物参考图
- 人物规范文件
- 质量检查

## 输入要求

- 至少一张人物清晰、轮廓完整、五官可辨认的照片。
- 优先选择正面或轻微侧面的全身照；只有半身照时，可以补全下装和鞋子，但必须向用户说明补全部分。
- 多张照片可用于身份复核，但不要把不同人的特征混合。
- 需要角色名称或昵称；用户未提供时只询问这一项。

原始照片是人物身份的唯一来源。不要根据审美偏好擅自改变年龄感、肤色、体型、发型、服装类型或显眼配件。

## 先提取固定身份

在内部记录以下可观察特征：

- 脸型与头部比例。
- 五官大小、位置和整体神态。
- 发型、发际线、发色和头发轮廓。
- 肤色、年龄感和体型轮廓。
- 固定服装的版型、颜色和主要结构。
- 鞋子、眼镜、手表、首饰等实际存在的配件。
- 整体气质与适合保留的辨识点。

只描述视觉事实，不猜测姓名、职业、民族、健康、政治、宗教、性取向或其他敏感属性。

## 角色设定板

生成一张 3:4 或 4:5 竖版“复古扁平立体角色设定图”。

固定版式：

1. 顶部居中写角色名称。
2. 标题下方小字写“角色设定”。
3. 中上部放一个最大的主角色全身像，站在简洁圆形底座上，姿态自然放松。
4. 底部横向排列四个小角色视图：正面 / FRONT、左侧 / LEFT SIDE、背面 / BACK、右侧 / RIGHT SIDE。

四视图必须是同一角色，保持同一个脸型、发型、服装、鞋子、配件、颜色和身体比例。背面不得凭空增加图案或配件。

视觉风格：扁平为主、轻微立体、低细节、低饱和、柔和阴影、哑光材质、轻微复古颗粒、浅米白或暖白设定板背景、干净排版和充足留白。

不要加入：左侧配件区、配色区、人物介绍、性格说明、长段文字、多余品牌、无关英文、乱码、复杂场景、写实摄影、二次元、潮玩盲盒、过度可爱或大头娃娃化。

## 角色设定板提示骨架

把内部提取的真实身份特征填入提示，不把方括号原样交给图像工具：

```text
请根据上传的人物照片，生成一张“复古扁平立体角色设定图”。

角色名称：[角色名]

把照片中的真人转化为可长期复用的个人 IP。人物照片是唯一身份来源，严格保留：[脸型、五官比例、发型、发际线、肤色、年龄感、体型轮廓、固定服装、鞋子、实际配件和整体气质]。采用扁平为主、轻微立体、低细节、低饱和、柔和阴影、哑光质感和轻微复古颗粒；不要写实、二次元、潮玩化、过度可爱或大头娃娃化。

服装参考原照片，只做必要简化，不更换服装类型，不增加品牌和无关配件。

使用 3:4 或 4:5 竖版设定板：顶部居中写“[角色名]”，下方小字写“角色设定”；中上部放最大的主角色全身像和简洁圆形底座；底部依次排列正面 / FRONT、左侧 / LEFT SIDE、背面 / BACK、右侧 / RIGHT SIDE 四个小视图。

四视图必须是完全一致的同一角色：相同脸型、发型、服装、鞋子、配件、颜色和身体比例。

不要左侧配件区、配色区、人物介绍、性格说明、长段文字、多余英文、乱码或复杂场景。
```

## 干净人物参考图

角色设定板完成后，再生成一张同一角色的独立全身图：

- 单人物、自然站姿、正面或轻微侧面。
- 优先透明背景；工具不支持透明时使用延伸到四边的纯白背景。
- 不包含标题、标签、边框、底座、四视图、配色板、说明文字或其他人物。
- 人物外观、服装、鞋子、配件、比例和设定板完全一致。
- 用于后续场景生成的默认身份参考，不承担文章画风参考。

## 人物规范文件

生成 `character-spec.md`，使用以下结构：

```markdown
# <角色名>角色规范

## 正式视觉资产
- 默认身份参考：<clean reference>
- 多角度参考：<character sheet>

## 固定身份特征
- 脸型与五官比例：...
- 发型与发际线：...
- 肤色、年龄感与身体比例：...
- 整体气质：...

## 固定服装与配件
- 上装：...
- 下装：...
- 鞋子：...
- 配件及佩戴位置：...

## 允许变化
- 动作、姿态、朝向、视线和轻微表情。

## 禁止漂移
- 不得改变的具体项目。

## 可复用身份提示词
> 一段只描述固定身份的紧凑提示词。
```

不要把文章场景中的道具、背景或偶然动作写成固定人物特征。

## 质量检查

- 主角色和四视图是否为同一人物。
- 脸型、发型、发际线、肤色和年龄感是否保留。
- 服装、鞋子、配件和佩戴位置是否一致。
- 是否错误复制了原照片背景、其他人物、水印或文字。
- 是否出现多余配件、品牌、装饰或不需要的内容。
- 干净参考图是否只有一个完整人物。
- 人物规范是否只记录视觉身份，没有敏感推断。

任何一项明显失败时，先针对性修订，再注册草稿。不要用低质量角色包进入文章配图阶段。
