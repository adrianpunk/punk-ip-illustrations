# 图像生成与修订接口

## 参考图选择

- 默认身份参考：`../assets/punk-character-reference-clean.png`。它是单人物透明背景图，不含设定板排版信息。
- 辅助角度参考：`../assets/punk-character-sheet.png`。只有需要侧面、背面或身份复核时才加入。
- 使用设定板时，明确标注其角色为 `identity/turnaround reference only`，不得把它当作背景、配色、文字、构图或版式参考。
- 角色设定板中的米色背景、标题、边框、配件展示、配色板和方向文字都不是输出内容。

## 新图生成

1. 使用宿主内置的 image generation 工具或等价生成接口。
2. 把干净人物参考图转换为绝对路径并作为 reference image 传入。接口支持 `referenced_image_paths` 时，传入：

   ```text
   ["<skill-root>/assets/punk-character-reference-clean.png"]
   ```

3. 只有当前动作确实需要其他角度时，才追加设定板为第二张参考图。
4. 在每张提示中重新声明纯白 16:9 页面、Punk 固定身份、角色本人左手腕、单一观点和禁止复制设定板元素。
5. 每个认知锚点单独调用一次工具；不要一次生成多宫格来代替多张文件。

## 修改已有图片

1. 同时传入两类图片：
   - Image 1：待修改原图，角色为 `edit target`。
   - Image 2：`punk-character-reference-clean.png`，角色为 `identity reference`。
2. 人物角度发生漂移时，可增加设定板作为第三张 `turnaround reference`。
3. 每次只改一个主要问题，明确写出 `change only X; keep everything else unchanged`。
4. 不覆盖上一版结果；保存为 `-v2`、`-v3` 等新文件。

## 检查与重试

按以下顺序处理失败，每次只做一次针对性修正：

1. 核心观点或物理关系错误：保留人物参考，重新生成整个场景。
2. 人物身份漂移：强化固定身份描述，并同时传入干净参考图；确有角度需要时再加入设定板。
3. 出现米色背景、标题、边框或配色板：移除设定板，只使用干净参考图，重新强调纯白页面和禁止设定板元素。
4. 手表镜像：明确“角色本人左手腕；正面视角通常位于画面右侧”，只修正佩戴侧。
5. 文字错误：优先减少非必要文字；只有局部编辑可靠时才修改文字，否则重新生成该张。
6. 元素过多或海报化：删除第二隐喻、完整空间背景、大标题和装饰物，只保留一个关系与 1—3 个主要物件。

同一张图片最多进行两次针对性重试。仍未达到要求时，保留最佳版本，并在交付中说明未解决的限制，不无限重试。

## 保存与实际路径

1. 内置生成工具通常先返回宿主管理的本地文件路径；先记录该实际路径。
2. 能写入目标项目时，把最终版本复制到 `.punk-ip-assets/<article-slug>/`，再报告复制后的绝对路径。
3. 项目不可写时，尝试用户目录下的 `.punk-ip-assets/<article-slug>/`。
4. 两个目标都不可用，或宿主不允许移动文件时，保留工具返回的实际本地路径并原样报告。
5. 不声称图片已保存到一个不存在、不可写或尚未成功复制的路径。
