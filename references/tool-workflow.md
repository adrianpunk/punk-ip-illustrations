# 图像生成、编辑与保存接口

## 工具选择

使用宿主内置的 image generation 工具或等价图片生成/编辑接口。不同宿主工具名不同时，保持相同的参考图角色和调用顺序。

## 创建角色设定板

1. 把用户人物照片作为 `identity source` 传入。
2. 使用 `ip-builder.md` 的固定版式和内部提取的身份特征生成竖版设定板。
3. 照片只提供人物身份和实际服装信息，不提供背景、构图、文字、水印或其他人物。
4. 多张照片时明确它们是同一个人的身份补充；不要混合不同人物。
5. 输出后检查主角色和四视图一致性。

接口支持 `referenced_image_paths` 时传入照片绝对路径数组：

```text
["<absolute-path-to-user-photo>"]
```

## 创建干净人物参考图

同时传入：

- 已生成设定板：`identity/turnaround reference`。
- 原始人物照片：`identity source`，若仍可访问。

明确要求单人物全身、透明或纯白背景，并禁止设定板标题、边框、底座、四视图、方向标签和说明文字。干净参考图是后续文章插图的默认人物参考。

## 修订角色

同时传入：

- 待修改设定板或干净人物图：`edit target`。
- 原始人物照片：`identity source`，若可访问。
- 当前干净人物参考：`identity reference`。

每次只修改一个主要问题，明确写出：`change only X; keep all unmentioned identity traits unchanged`。修订设定板后同步检查或重建干净参考图，不让两者指向不同角色版本。

## 生成文章插图

从角色 manifest 解析绝对路径：

- 默认传入 `assets.clean_reference`，标记为 `identity reference only`。
- 需要侧面、背面或多角度时才追加 `assets.sheet`，标记为 `turnaround reference only`。
- 不传原始真人照片，除非用户明确要求修复身份且仍授权使用。

每张提示重新声明：

- 当前角色固定身份来自角色包。
- 只改变动作、姿态、方向、视线和轻微表情。
- 16:9 横版纯白页面。
- 一个认知锚点、一个物理关系和 1—3 个主要物件。
- 禁止复制设定板背景、标题、边框、标签和四视图排版。

每个认知锚点单独调用一次生成工具，不用多宫格代替多张文件。

## 修改文章插图

至少同时传入：

- 待修改原图：`edit target`。
- 当前角色干净参考图：`identity reference`。

角度漂移时可增加角色设定板作为第三张 `turnaround reference`。每次只改一个主要问题，不覆盖上一版结果。

## 检查与重试顺序

1. 核心观点或物理关系错误：保留身份参考，重新生成场景。
2. 人物身份漂移：强化 `character-spec.md` 的固定身份，并重新传入干净参考。
3. 角度错误：加入设定板作为多角度参考，但禁止复制版式。
4. 出现米色背景、标题、边框或四视图：移除设定板，只用干净参考并强调纯白页面。
5. 配件位置或左右侧镜像：引用人物规范中的具体佩戴侧，只修正该项。
6. 文字错误：减少非必要文字；局部编辑不可靠时重新生成该张。
7. 元素过多或海报化：删除第二隐喻、完整空间背景、大标题和装饰物。

同一张图片最多两次针对性重试。仍未达到要求时保留最佳版本，并说明限制，不无限重试。

## 保存与实际路径

1. 先记录图像工具返回的实际本地路径。
2. 角色创建结果通过 `character_registry.py register` 复制进角色包。
3. 文章插图复制到 `<runtime-root>/illustrations/<article-slug>/`。
4. 目标不可写或宿主不允许移动时，保留工具实际路径并原样报告。
5. 不声称文件已写入不存在、不可写或尚未成功复制的路径。

## 工具降级

宿主没有图像生成能力时：

- 角色阶段：输出角色设定板提示词、干净参考图提示词、建议资产路径和人物规范草稿，状态保持未注册或 `draft`。
- 文章阶段：输出每张图的完整提示词、当前角色参考图路径和保存计划。
- 明确标注图片尚未生成，不伪造文件。
